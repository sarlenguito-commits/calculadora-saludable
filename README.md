# Calculadora Saludable

Calculadora web que estima IMC, calorías diarias, distribución de macronutrientes,
hidratación y actividad física recomendada según tus datos personales y objetivo
(bajar, mantener o ganar peso). Incluye un tip diario personalizado y recetas
sugeridas según tu objetivo, además de un catálogo completo de recetas para explorar.

## Funcionalidades
- Cálculo de IMC y categorización (según rangos de la OMS)
- Rango de peso saludable estimado
- Calorías diarias sugeridas (ecuación de Mifflin-St Jeor)
- Distribución de macronutrientes según objetivo
- Método del plato (raciones visuales por comida)
- Hidratación sugerida
- Actividad física recomendada según objetivo
- Tip del día personalizado
- Recetas sugeridas (2 al azar según objetivo) + catálogo completo de 12 recetas

## Tecnologías
HTML, CSS, JavaScript (vanilla, sin librerías ni frameworks)
